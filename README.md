# Brandify — الموقع ولوحة التحكم

موقع Brandify Marketing Agency: موقع عام ثنائي اللغة (عربي RTL / إنجليزي LTR) + لوحة تحكم كاملة لإدارة الطلبات والأعمال والمحتوى.

---

## التشغيل على جهازك

المتطلبات: **Node.js 20+** فقط. قاعدة البيانات (PostgreSQL) تعمل تلقائيًا من داخل المشروع بدون تثبيت.

```bash
npm install
```

أول مرة فقط:

```bash
copy .env.example .env
```

ثم افتح `.env` وضع قيمة عشوائية طويلة في `BETTER_AUTH_SECRET` (أو استخدم الأمر المكتوب بجانبها).

```bash
npm run db:start
```

(اتركه يعمل في نافذة، ثم في نافذة أخرى:)

```bash
npm run db:migrate
```

```bash
npm run db:seed
```

```bash
npm run admin:create -- --email brandifyagency9@gmail.com --name "Brandify"
```

كلمة المرور تُحفظ في ملف `.admin-credentials.local` (غير مرفوع على Git). **غيّرها بعد أول دخول** من: لوحة التحكم ← الإعدادات ← حسابي.

### التشغيل اليومي

```bash
npm run dev
```

يشغّل قاعدة البيانات والموقع معًا:

- الموقع: http://localhost:3000 (يتحول تلقائيًا إلى `/ar`)
- لوحة التحكم: http://localhost:3000/admin

### أوامر مفيدة

| الأمر | الوظيفة |
|---|---|
| `npm run dev` | تشغيل الموقع + قاعدة البيانات |
| `npm run build` ثم `npm start` | نسخة الإنتاج محليًا |
| `npm test` | الاختبارات |
| `npm run typecheck` | فحص الأنواع |
| `npm run db:seed -- --reset` | إعادة المحتوى الافتراضي (لا يمس الطلبات أو المستخدمين) |
| `npm run admin:create -- --email ...` | إنشاء مدير أو إعادة تعيين كلمة مروره |
| `node scripts/prepare-brand-assets.mjs logo.jpg` | إعادة استخراج ملفات اللوجو إذا تغيّر |

قاعدة البيانات المحلية محفوظة في `%USERPROFILE%\.brandify\pgdata`.

## ما الذي تديره من لوحة التحكم

| القسم | ماذا يمكنك فعله |
|---|---|
| **نظرة عامة** | الطلبات، نقرات واتساب الحقيقية، المحتوى المنشور، آخر النشاطات |
| **الطلبات** | بحث وفلترة، تغيير الحالة (جديد ← تم التواصل ← مؤهل ← عرض سعر ← تم الاتفاق / لم يتم)، ملاحظات داخلية، تصدير CSV، مصدر الطلب وUTM |
| **الأعمال** | إضافة/تعديل/حذف/ترتيب المشاريع، صور وفيديو، تحويل أي مشروع إلى دراسة حالة، مشاريع تصورية، تصنيفات الفلاتر |
| **الخدمات** | 5 أقسام قابلة للتعديل والترتيب والإخفاء، خدمات فرعية، فوائد، تسليمات، خطوات، رسالة واتساب خاصة بكل خدمة |
| **آراء العملاء / اللوجوهات / الفريق / الأسئلة الشائعة** | إضافة وتعديل وترتيب ونشر/إخفاء |
| **محتوى الصفحات** | الرئيسية، من نحن، طريقة العمل، الخصوصية، الشروط |
| **SEO** | عنوان ووصف وصورة مشاركة لكل صفحة |
| **مكتبة الوسائط** | رفع وتنظيم وحذف — الصور تُضغط تلقائيًا إلى WebP بعدة مقاسات |
| **الإعدادات** | التواصل، السوشيال ميديا (TikTok وLinkedIn وغيرها جاهزة)، أزرار الدعوة، **حقول النموذج**، الهوية، أكواد التتبع، الفوتر، الحساب، المستخدمين |

### قبل الإطلاق — من لوحة التحكم

1. **الفريق والمؤسس:** اكتب اسمك وأضف صورتك أو فيديو، ثم فعّل الظهور.
2. **الأعمال:** أضف مشاريعك الحقيقية. استبدل المشاريع التصورية الخمسة أو أخفِها.
3. **آراء العملاء:** أضف الآراء الحقيقية وانشرها (القسم مخفي حتى أول رأي منشور).
4. **الرئيسية ← شريط الريلز:** أضف فيديوهاتك (القسم مخفي حتى تضيف ملفات).
5. **الإعدادات ← التتبع:** أضف GA4 / Meta Pixel / TikTok Pixel عند توفرها.
6. **الخصوصية والشروط:** راجعها مع مختص.

## التقنيات

Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · PostgreSQL + Drizzle ORM · Better Auth · Zod · sharp · Tiptap

```
src/
├── app/[locale]/        الموقع العام (ar / en)
├── app/admin/           لوحة التحكم
├── app/api/             تسجيل الدخول، الرفع، التصدير، التتبع
├── components/site      مكونات الموقع
├── components/admin     مكونات لوحة التحكم
├── content/             مخطط وافتراضيات المحتوى والإعدادات
├── server/              قاعدة البيانات، الخدمات، الصلاحيات، التخزين، الإشعارات
├── lib/                 اللغات، SEO، واتساب، التحقق
└── messages/            نصوص الواجهة الثابتة
```

### الأمان

- لوحة التحكم محمية بتسجيل دخول حقيقي، وكل إجراء يتحقق من الصلاحية على الخادم (مدير / محرر).
- كلمات المرور مشفّرة، الجلسات في قاعدة البيانات، وحماية من محاولات الدخول المتكررة.
- كل المدخلات تُتحقق منها على الخادم (Zod)، والنصوص المنسقة تُنظّف من أي كود.
- الرفع يتحقق من محتوى الملف الفعلي (وليس الامتداد فقط)، وSVG مرفوض.
- النموذج محمي من السبام (حقل مخفي + زمن تعبئة + حد للطلبات لكل IP).
- لا توجد مفاتيح سرية في الكود؛ كل الأسرار في `.env`.

### إشعارات الطلبات بالبريد (اختياري)

ضع `RESEND_API_KEY` و`LEAD_NOTIFY_EMAIL` في `.env` ليصلك بريد "New Lead from Brandify Website" مع كل طلب. بدونها يعمل كل شيء عاديًا.

## النشر (لاحقًا)

لا يحتاج المشروع أي شراء الآن. عند النشر:

- **الخيار الأبسط (موصى به للبداية):** سيرفر VPS صغير واحد (Node + PostgreSQL + قرص دائم للصور). يعمل مع الكود الحالي كما هو.
- **خيار السحابة (Vercel + Neon):** يتطلب نقل الصور لتخزين سحابي (مثل Cloudflare R2). طبقة التخزين جاهزة لإضافة هذا بدون تغيير باقي الكود.

متغيرات الإنتاج: `DATABASE_URL`، `BETTER_AUTH_SECRET`، `BETTER_AUTH_URL` و`NEXT_PUBLIC_SITE_URL` (رابط الدومين).
